# Git Commit Policy

All commits in this repository must use the sole author and committer:

    Adekoya Oluwafemi A. <heykoyr@gmail.com>

Do not add Claude, Anthropic, or any other AI co-author trailer or attribution
to commit messages. In particular, do NOT add `Co-authored-by` / `Co-Authored-By`
trailers for Claude or Anthropic, and do not commit as any other name or email
(e.g. `heyadekoya@gmail.com`, `adkoy`, or a `users.noreply.github.com` address).
Verify the author, committer, and message trailers before creating each commit.

## Sourcing

Six store screenshots already exist on the [Play listing](https://play.google.com/store/apps/details?id=com.koyr.fieldsnap). Use the originals rather than re-capturing, unless the store set is out of date.

## Rules

- Real screenshots of the shipped app only. No mockups of screens that do not exist, and no marketing-site illustrations presented as product UI.
- Scrub real user data. Use the built-in template `mockData` values if a clean record is needed.
- PNG for stills, GIF or MP4 for motion. Keep each file under ~2 MB so the README loads.
- Every `<img>` needs an `alt`.
